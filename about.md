# About

I am Banani Ghosh, a software engineer working on LLM inference performance. I write first-principles notes on how GPUs and AI accelerators turn hardware into tokens: rooflines, memory bandwidth, kernels, and the serving systems built on top of them.

## Now

I am a Software Development Engineer at Amazon, working on Amazon Quick, a production multi-agent system. My work centers on inference latency and throughput: optimizing agentic execution graphs, routing requests across model tiers to cut token cost, and building low-overhead telemetry that measures latency at every step of an agent pipeline.

## Open source

I contribute to [vLLM](https://github.com/vllm-project/vllm):

- Config-driven auto-tuning and benchmark tooling for a GPU inference kernel path, up to 2.46x faster on NVIDIA B200.
- Utility-driven adaptive-k speculative decoding for MoE inference, which sets the draft-token budget per request (in progress).
