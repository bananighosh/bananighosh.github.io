# About

I am a software engineer at Amazon, working on LLM inference performance and ML systems. My work spans execution graph optimization, latency instrumentation, model-serving efficiency, and model routing for a production multi-agent system.

Outside work, I contribute to [vLLM](https://github.com/vllm-project/vllm). I built an auto-tuning framework for the Mamba `selective_state_update` kernel, benchmarked on NVIDIA B200 and GB10 with up to 2.46x speedup ([#41398](https://github.com/vllm-project/vllm/pull/41398), merged via [#43083](https://github.com/vllm-project/vllm/pull/43083)). I am now working on utility-driven adaptive-k speculative decoding for MoE models ([#44506](https://github.com/vllm-project/vllm/issues/44506)).

Before Amazon, I spent nine years at Adobe building large-scale distributed systems. I hold an MS from NYU, specializing in high-performance ML systems.

This blog is where I work through GPU and accelerator performance from first principles.
