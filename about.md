# About

I am Banani Ghosh, a software engineer working on LLM inference performance and ML systems. I write about GPU kernels, memory-bound decode, speculative decoding, and serving efficiency, usually from first principles and backed by measurements on Hopper and Blackwell hardware.

I contribute to [vLLM](https://github.com/vllm-project/vllm). Code lives on [GitHub](https://github.com/bananighosh).
