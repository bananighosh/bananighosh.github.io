Fleet

Formulas: N_p = ⌈λ·P ÷ (ρ·μ_p)⌉, N_d = ⌈λ·O ÷ (ρ·μ_d)⌉. Sequences in flight follow Little's law, λ · O · TPOT, each holding (P + O/2) tokens of KV cache on average. KV capacity per node is HBM minus the weight copies, before the activation and runtime buffers your serving engine reserves, so treat it as an upper bound.
